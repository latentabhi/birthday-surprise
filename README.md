# 🎂 Happy Birthday Website

A cute, interactive birthday surprise & apology website built with love, pastel scrapbook aesthetics, Bubu & Dudu stickers, and interactive games! 💖

## ✨ Features
- 🌸 **Pastel Pink Scrapbook Aesthetic**: Lined paper textures, washi tape, Polaroid frames, and floating hearts.
- 🌡️ **Interactive Gussa Meter**: Cool down her anger from 99% to 0% with sweet compliments.
- 📸 **Bubu & Dudu Polaroids**: Reliving all the cute truths and quirks.
- 🎟️ **Redeemable Love Coupons**: Claimable birthday passes stamped for the Queen.
- 🥺 **"Mujhe Maaf Kardiya?" Game**: Evasive "Nahi" button that dodges clicks, and an "Itni Jaldi?!" tease popup on "Haan".
- 💌 **Handwritten Love Letter**: Warm and heartfelt note.
- 🎵 **Cute Lo-fi Chime Melody**: Built-in background music.
